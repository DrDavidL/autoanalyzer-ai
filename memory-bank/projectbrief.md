# Project Brief

## Core Requirements and Goals

This project, "autoanalyzer-ai", is intended to be an automated data analysis and visualization tool. The primary goal is to take a dataset as input, perform exploratory data analysis (EDA), identify key insights, and generate visualizations and a summary report.

## Scope

- **Input:** CSV files containing datasets.
- **Processing:**
    - Data cleaning and preprocessing.
    - Statistical summary generation.
    - Correlation analysis.
    - Automated visualization generation (e.g., histograms, scatter plots, etc.).
- **Output:** A comprehensive report summarizing the findings, including visualizations.
