# Tech Context

## Technologies Used

- **Programming Language:** Python 3
- **Core Data Science Libraries:**
    - **Pandas:** For data manipulation and analysis.
    - **NumPy:** For numerical operations.
    - **Scikit-learn:** For machine learning and data preprocessing.
- **Visualization:**
    - **Matplotlib & Seaborn:** For generating static plots.
    - **Streamlit:** For creating interactive web apps.
- **LLM Integration:**
    - **Langchain:** For building applications with large language models.
    - **OpenAI:** For interacting with OpenAI's language models.
- **Reporting:**
    - **python-docx:** For creating and manipulating DOCX files.
    - **markdown2:** For converting Markdown to HTML.
- **Containerization:**
    - **Docker:** For creating a reproducible environment for the application.

## Development Setup

The development setup requires Python 3 and the dependencies listed in `requirements.txt`. The application can be run directly from the command line or as a containerized service using Docker.

## Technical Constraints

- The application is designed to process one CSV file at a time.
- The performance of the analysis may depend on the size of the input dataset and the complexity of the analysis performed.
- The quality of the insights generated by the LLM is dependent on the quality of the prompts in `prompts.py`.
