# Product Context

## Problem Solved

This project aims to solve the time-consuming and often repetitive process of initial data exploration. Data scientists and analysts spend a significant amount of time performing the same basic steps for every new dataset. This tool automates that initial analysis, freeing them up to focus on more complex and domain-specific questions.

## How It Should Work

The user should be able to provide a CSV file and, with minimal configuration, receive a detailed report. The process should be as automated as possible, but also allow for some customization of the analysis parameters.

## User Experience Goals

- **Simplicity:** The tool should be easy to use, even for those with limited programming experience.
- **Clarity:** The output report should be well-structured, easy to read, and visually appealing.
- **Speed:** The analysis should be performed quickly, providing rapid insights.
